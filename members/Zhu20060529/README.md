\# 我的 Git 学习笔记



\## 第一次 Git 实验总结

1\. `git add` 的作用是：

将工作区修改的文件加入暂存区，标记文件，为后续提交做准备。



2\. `git commit` 的作用是：

把暂存区的改动打包，在本地Git仓库生成一条带版本号的提交记录。



3\. 本次实验中 `git restore notes.md` 的作用是：

撤销工作区内还没有add的临时修改，恢复文件到暂存区/最近一次提交的版本。



4\. `commit` 与 `push` 的区别是：

commit 只保存改动到\*\*本地电脑仓库\*\*；push将本地已经commit的版本上传推送到GitHub远程仓库。
