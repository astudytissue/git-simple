## 第一次 Git 实验总结
1. `git add` 的作用是：把工作区中新增或修改的文件加入暂存区，标记这些改动准备提交，此时改动还未正式存入本地仓库。
2. `git commit` 的作用是：把暂存区中的所有改动永久保存到本地 Git 仓库，生成一条带唯一 ID 的提交记录，仅保存在本地，不会自动上传到远程仓库。
3. 本次实验中 `git restore notes.md` 的作用是：撤销工作区中 notes.md 尚未暂存的修改，将文件恢复到上一次 commit 提交的版本。
4. `commit` 与 `push` 的区别是：commit 是把改动保存到本地仓库，只影响本机；push 是把本地的提交记录上传同步到远程 GitHub 仓库，其他人才能看到。
