# 我的 Git 学习笔记

## 第一次 Git 实验总结
1. `git add` 的作用是：将工作区的改动添加到暂存区，标记哪些文件的修改需要被提交到本地仓库。
2. `git commit` 的作用是：把暂存区中的所有改动生成一个版本快照，永久保存到本地Git仓库，记录这次修改的内容和备注信息。
3. 本次实验中 `git restore notes.md` 的作用是：丢弃工作区中还没有执行`git add`的未暂存修改，把notes.md恢复到上一次commit提交的状态，撤销临时追加的无关文字。
4. `commit` 与 `push` 的区别是：`commit`是把改动保存到**你电脑本地的Git仓库**，只有你自己能看到；`push`是把本地的提交记录上传到**GitHub远程仓库**，其他组员和老师才能看到你的作业内容。
