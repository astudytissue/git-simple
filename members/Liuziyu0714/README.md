 我的 Git 学习笔记

## 第一次 Git 实验总结

1. `git add` 的作用是：把工作区中修改或新增的文件添加到暂存区（staging area），为下一次提交做准备。
2. `git commit` 的作用是：将暂存区中的内容作为一个快照永久保存到本地仓库的历史记录中，并生成唯一的提交 ID。
3. 本次实验中 `git restore notes.md` 的作用是：丢弃 notes.md 在工作区中尚未暂存的修改（即临时追加的那句话），将文件恢复为上次提交时的版本。
4. `commit` 与 `push` 的区别是：commit 是把改动保存到本地仓库；push 是把本地仓库的提交上传到远程仓库，让其他人也能看到。
